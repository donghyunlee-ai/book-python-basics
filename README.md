# AI 시대의 파이썬 기본기 — 예제 코드

> AI ERA SERIES 01 · 이동현 지음

『AI 시대의 파이썬 기본기』의 장별 예제 코드와 실습 데이터 저장소입니다.
경험 제로에서 시작해 변수·자료형부터 함수, 클래스, 모듈까지 — 성적 관리
프로그램 하나를 전권에 걸쳐 완성하며 기본기를 쌓는 책입니다.

## 사용법

이 책의 학습 규율은 **예측 → 실행 → 대조**입니다. 코드를 실행하기 전에
출력을 먼저 예측해 적어 보세요. 예측이 틀린 순간이 배울 차례입니다.

```bash
python3 code/ch03/same_rules.py
```

## 구조

```
code/
├── ch01/  1장  파이썬과 첫 만남
├── ch02/  2장  숫자와 문자열
├── ...
└── ch14/  14장 에필로그 (titanic.csv 포함)
```

- 각 장 폴더의 `.py` 파일은 본문 코드 블록의 원본입니다. 본문과 동일함을
  실행으로 검증했습니다.
- `exercises.py` / `corner.py`는 각 장 연습문제·[AI와 짝 코딩] 코너의 코드입니다.

## 실행 환경

- Python 3.12 이상 (본문 전체 코드는 3.12·3.14 두 버전에서 실행 확인)
- 대부분 표준 라이브러리만 사용합니다. 14장 일부 예제는 `pandas`가 필요합니다.

## 실습 데이터

- `code/ch14/titanic.csv` — 891행, `Name`·`Sex`·`Age`·`Survived` 열 포함.
  다른 경로로 데이터를 구하더라도 이 규격이면 14장 데모가 그대로 동작합니다
  (책 부록 C 참조).
