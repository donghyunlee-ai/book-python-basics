# AI 시대의 파이썬 기본기 — 예제 코드

> AI ERA SERIES 01 · 이동현 지음

『AI 시대의 파이썬 기본기 — 경험 제로에서 시작하는 첫 파이썬 수업』의
장별 예제 코드와 실습 데이터 저장소입니다. 경험 제로에서 시작해 변수와
자료형부터 함수, 클래스, 모듈, 예외처리까지 익히며, 러닝 프로젝트
**‘수학 도우미’**를 전권에 걸쳐 완성하는 책입니다. 7장의 최대공약수·소수
계산에서 출발해 8장에서 함수로 부품화하고, 9장에서 결과를 파일에 저장하고,
11장에서 클래스로, 12장에서 패키지로, 13장에서 예외 처리로 견고하게 만듭니다.

도서 안내(구매처·정오표·독자 자료): [donghyunlee.kr/books/](https://donghyunlee.kr/books/)

## 사용법

이 책의 학습 규율은 **예측하라, 실행하라, 대조하라**입니다. 코드를 실행하기
전에 출력을 먼저 예측해 적어 보세요. 예측이 틀린 순간이 배울 차례입니다.

```bash
python3 code/ch03/same_rules.py
```

파일을 읽고 쓰는 예제(9장, 13장 프로젝트, 14장)는 해당 장 폴더로 이동한 뒤
실행하세요. 파이썬은 터미널이 서 있는 폴더를 현재 폴더로 삼기 때문입니다.

```bash
cd code/ch14 && python3 demo.py
```

## 저장소 구성

| 위치 | 내용 |
|---|---|
| `code/` | 장별 예제 코드와 실습 데이터(아래 구조) |
| `docs/setup.md` | 부록 C 환경 가이드의 최신 갱신판 — 설치 확인, 터미널, AI 제안 끄기, pip와 가상환경 |
| `docs/prompts-updates.md` | 부록 D 프롬프트 모음의 변경 로그(인쇄판 이후 바뀐 것만) |
| `extras/advanced-problems.md` | 부록 B가 이월한 심화 문항 묶음(문항만, 풀이는 독자 자료) |
| `ERRATA.md` | 정오표 |

책과 저장소의 안내가 다를 때는 저장소가 최신입니다(부록 C의 대원칙).

```
code/
├── ch01/  1장  시작하기 — AI 시대에 왜 기본기인가
├── ch02/  2장  숫자와 문자열
├── ch03/  3장  리스트와 튜플
├── ch04/  4장  딕셔너리와 집합
├── ch05/  5장  연산자
├── ch06/  6장  조건문
├── ch07/  7장  반복문
├── ch08/  8장  함수
├── ch09/  9장  파일 입출력
├── ch10/  10장 파이썬다운 코드
├── ch11/  11장 클래스
├── ch12/  12장 모듈과 패키지 (mathtools 패키지, exercises/ 폴더)
├── ch13/  13장 예외처리 (project/ 폴더에 수학 도우미 프로젝트)
└── ch14/  14장 에필로그 — 데이터의 세계 맛보기 (titanic.csv 포함)
```

- 각 장 폴더의 `.py` 파일은 본문 코드 블록의 원본입니다. 본문과 동일함을
  실행 하네스로 대조해 검증했습니다.
- `exercises.py`는 각 장 연습문제의 코드입니다(12장은 `exercises/` 폴더).
  `corner.py`는 "AI와 짝 코딩" 코너의 코드입니다(코너 코드가 있는 장에만 있습니다).
- 책의 모든 코드는 본문에 완전한 형태로 인쇄되어 있습니다. 이 저장소는
  입력 편의를 돕는 보조 수단입니다.

책이 저장소에 있다고 안내한 자료 가운데 다음은 **책을 가진 독자에게만** 제공합니다.

교수자용 해답지와 평가용 문항은 소속 기관 이메일로 신청을 받습니다. 절차는 같은
페이지에 있습니다.

## 실행 환경

- Python 3.12 이상. 책의 기준 실행 환경은 구글 코랩(2026년 9월 기준 Python 3.13)이며,
  본문 전체 코드는 3.12 실행 하네스로 본문과 대조하고 3.13에서 교차 확인했습니다.
- 표준 라이브러리만 사용합니다. 14장의 `demo.py`·`reverse_links.py`만
  `pandas`가 필요합니다.
