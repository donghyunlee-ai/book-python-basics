## 0. 먼저 확인할 것 — 어느 파이썬이 대답하는가

부록 C 1단계와 "운영체제별 확인 명령"의 요약입니다. 설치 뒤에는 언제나 이 세 가지를
먼저 확인합니다.

| 목적 | 윈도우 | 맥 |
|---|---|---|
| 버전 확인 | `py --version` (반응이 없으면 `python --version`) | `python3 --version` |
| 어느 엔진이 대답하는가 | `py --list-paths` | `which python3` |
| pip 확인 | `py -m pip --version` | `python3 -m pip --version` |

**윈도우의 흔한 막힘**

- 설치 관리자 첫 화면의 **"Add python.exe to PATH"** 체크를 켜지 않으면 "명령을 찾을 수
  없음"이 납니다. 설치 관리자를 다시 실행해 이 항목을 켜고 설치를 마칩니다.
- `python`을 쳤는데 **Microsoft Store 창이 열리면** 윈도우의 "앱 실행 별칭"이 명령을
  가로챈 것입니다. 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 `python.exe`와
  `python3.exe`를 끄거나, 그냥 `py`를 씁니다. 검색어: "앱 실행 별칭".

**맥의 흔한 막힘**

- `python3`를 처음 치면 명령줄 개발자 도구 설치 안내가 뜹니다. 수락해 설치를 마친 뒤
  다시 버전을 확인합니다.
- 패키지를 설치할 때 `externally-managed-environment`라는 에러가 나면 시스템이 자기
  파이썬을 보호하는 것입니다. 4절의 가상환경을 만들고 그 안에 설치합니다.

## 1. VS Code — 파이썬 확장과 인터프리터 (부록 C 2~4단계)

- **확장 설치**: 확장 탭(`Ctrl+Shift+X`, 맥 `Cmd+Shift+X`)에서 "Python"을 검색해 게시자가
  Microsoft인 것을 설치합니다. 식별자는 `ms-python.python`입니다.
- **인터프리터 선택**: 명령 팔레트(`Ctrl+Shift+P`, 맥 `Cmd+Shift+P`)에서
  `Python: Select Interpreter`를 실행하고 0절에서 확인한 엔진을 고릅니다. 선택 결과는
  오른쪽 아래 상태 표시줄에 버전 숫자로 보입니다.
- **실행과 현재 폴더**: 편집기 오른쪽 위의 실행(▷) 버튼은 터미널을 열어 파일을
  실행하되, 현재 폴더를 파일이 있는 폴더가 아니라 **작업 영역 폴더**로 잡을 수 있습니다.
  9장·13장·14장처럼 파일을 읽고 쓰는 예제가 `FileNotFoundError`를 내면 통합 터미널에서
  `cd`로 그 장 폴더에 들어간 뒤 `python3 파일명.py`로 실행하세요. 설정에서
  `python.terminal.executeInFileDir`를 켜면 실행 버튼도 파일의 폴더에서 실행합니다.

## 2. 터미널을 여는 경로 (부록 C "터미널 열기"가 미룬 것)

| 환경 | 경로 | 단축키 |
|---|---|---|
| 윈도우 | 시작 메뉴에서 "터미널"(Windows Terminal, 기본은 PowerShell) 또는 "명령 프롬프트" | `Win+X` → 터미널 |
| 맥 | 응용 프로그램 → 유틸리티 → 터미널, 또는 Spotlight(`Cmd+Space`)에 "터미널" | — |
| VS Code | 메뉴 터미널 → 새 터미널 | ``Ctrl+` `` (맥도 `Ctrl`, 백틱 키) |

- PowerShell과 명령 프롬프트는 명령이 조금 다릅니다. 책의 `pwd`는 PowerShell에서
  동작하고, 명령 프롬프트에서는 `cd`만 치면 현재 폴더가 나옵니다. 폴더 내용은
  PowerShell `ls`, 명령 프롬프트 `dir`입니다.
- 특정 폴더에서 바로 열기: 윈도우 탐색기의 주소창에 `cmd`를 치고 Enter. 맥은 Finder에서
  폴더를 우클릭해 서비스 메뉴의 "폴더에서 새로운 터미널 열기"를 씁니다(보이지 않으면
  시스템 설정의 키보드 → 키보드 단축키 → 서비스에서 켭니다). 검색어: "폴더에서 터미널 열기".

## 3. AI 제안 끄기 (부록 C "AI 기능의 스위치"가 미룬 메뉴 경로)

원칙은 책과 같습니다. 기본기를 익히는 동안은 끄고, 코드 검증 훈련이나 실무에서는
켜되 부록 D의 의심 목록 12항으로 심사합니다.

**코랩 (2026-09 기준)**

- 메뉴 도구 → 설정 → "AI 어시스턴스" 탭. 생성형 AI 기능 사용에 관한 동의 항목과
  AI 기반 인라인(자동) 완성 표시 항목의 체크를 해제하고 저장합니다. 구글 계정 단위
  설정이라 모든 노트북에 적용됩니다.
- 성공 확인: 셀 옆의 Gemini 별 모양 아이콘과 입력 중 나타나던 회색 제안이 사라집니다.
- 화면 문구가 다르면 설정 창에서 "AI", "생성형", "완성"을 검색합니다.

**VS Code (2026-09 기준, 공식 FAQ 확인)**

- **한 번에 전부 끄기**: 설정(`Ctrl+,`, 맥 `Cmd+,`)에서 "Disable AI Features"를 검색해
  체크합니다. 설정 식별자는 `chat.disableAIFeatures`이며, 채팅과 인라인 제안을 숨기고
  Copilot 확장을 비활성화합니다. 제목 표시줄의 채팅 메뉴에 있는 "Learn How to Hide AI
  Features"에서도 같은 곳에 도달합니다.
- **인라인 제안만 끄기**: 상태 표시줄의 Copilot 아이콘을 눌러 완성(Completions)을
  끕니다. 설정 식별자는 `github.copilot.enable`, 다음 편집 제안은
  `github.copilot.nextEditSuggestions.enabled`입니다.
- 다시 켤 때는 같은 설정을 되돌리면 됩니다.

## 4. pip 문제 해결과 가상환경 (부록 C 마지막 소절이 미룬 "가상환경 안내")

**진단 순서**

1. `python3 -m pip --version`(윈도우 `py -m pip --version`)으로 pip가 대답하는지 봅니다.
2. `No module named pip`가 나오면 `python3 -m ensurepip --upgrade`로 pip를 되살립니다.
3. 설치는 됐는데 `import`가 안 되면 **다른 엔진**에 설치된 것입니다. 0절의 "어느 엔진이
   대답하는가"로 확인하고, 12장의 규칙대로 `python3 -m pip install 패키지이름` 꼴로 그
   엔진에 직접 설치합니다.
4. `externally-managed-environment`가 나오면 아래 가상환경을 만들어 그 안에 설치합니다.

**가상환경 세 단계**

책의 비유대로 "프로젝트마다 부품 상자를 따로 두는" 도구입니다. 이 책의 예제는 14장의
`pandas` 말고는 외부 패키지가 없으므로 가상환경 없이도 진행할 수 있습니다.

| 단계 | 맥 | 윈도우 |
|---|---|---|
| 만들기 (프로젝트 폴더에서) | `python3 -m venv .venv` | `py -m venv .venv` |
| 켜기 | `source .venv/bin/activate` | PowerShell `.venv\Scripts\Activate.ps1` / 명령 프롬프트 `.venv\Scripts\activate.bat` |
| 설치와 끄기 | `python -m pip install pandas` → `deactivate` | 같음 |

- 켜지면 프롬프트 앞에 `(.venv)`가 붙습니다. 그 상태에서 설치한 패키지는 이 폴더
  안에만 들어갑니다.
- PowerShell에서 "이 시스템에서 스크립트를 실행할 수 없으므로"라는 에러가 나면
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`를 한 번 실행한 뒤 다시 켭니다.
  검색어: "ExecutionPolicy".
- VS Code는 `.venv` 폴더를 찾아 인터프리터로 제안합니다. 상태 표시줄에 `('.venv': venv)`
  표기가 보이면 편집기도 같은 부품 상자를 쓰는 것입니다.

## 5. 코랩 보조 (부록 C "코랩 사용자를 위한 보조" 갱신)

- **올리기와 내려받기**: 왼쪽 폴더 아이콘으로 파일 패널을 열고, 업로드 아이콘을
  누르거나 파일을 끌어다 놓습니다. 내려받기는 파일을 우클릭해 다운로드를 고릅니다.
- **드라이브 연결**: 파일 패널의 드라이브 아이콘을 누르거나 셀에서 다음을 실행합니다.
  ```python
  from google.colab import drive
  drive.mount('/content/drive')
  ```
- **세션 소멸**: 코드는 노트북에 남고 파일은 사라집니다. 결과 파일은 드라이브에
  두거나 내려받아 두세요.
- **버전 확인**: 셀에서 `import sys; print(sys.version)`을 실행합니다. 책의 기준 환경은
  2026년 9월 현재 파이썬 3.13입니다. 버전이 올라가도 책의 코드는 그대로 동작합니다.
